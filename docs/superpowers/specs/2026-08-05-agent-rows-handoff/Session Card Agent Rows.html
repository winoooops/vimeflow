Heights measured live: —

1 · Hierarchy — tonal recess, no border

Rows sit in one shared recess panel (bg-wash-recess, darker than the card in dark themes, lighter-ink in Flexoki) with 6px of air above it. That reads as "inside the card" without a rule, and it groups 3 rows as one block instead of three floating lines. Type steps strictly down from the card: 13.5 title → 11.5 subtitle → 11 agent name → 10.5 message. State chip is flush-left with the card's text column, so the rows indent optically by their own 22px chip, not by extra padding.

2 · Five statuses — carried entirely by the chip

No status word, no separate dot: the chip is the status. Running is a rotating hairline ring (no glyph) in state-running; awaiting-you is state-awaiting, error state-error, done state-done, idle state-idle. Those five are the only colour names the row references — each aliases a semantic token (secondary / tertiary / error / success-muted / on-surface-muted), so every Lens theme recolours the whole state vocabulary by overriding the semantics, never the row. Fills stay ≤16% so the chips never compete with the card-level notification badge.

3 · State chip — universal, agent-agnostic

22px square, radius 6 — two-thirds of the 33px row. One vocabulary (↻ running · ! awaiting you · ✕ error · ✓ done · ◦ idle) in one tonal system, identical for every agent: the agent's name tells you who, the chip tells you what's happening. Three duplicate Kimi rows now read as three different states rather than three identical marks.

4 · No right slot — the message gets the width

A relative timestamp and a mini progress bar were both redundant: the card's meta row already reads "Running · 2m 14s", and the spinning chip already says work is in flight. Cutting them hands the latest message ~44px — roughly 8 more characters at 10.5px, the difference between a readable line and a stub. Two columns only: grid-cols-[22px_minmax(0,1fr)], so nothing can shift when state changes.

5 · Density & 6 · reduced motion

33px rows + 4px panel padding: 1 agent adds ~45px (card ≈ 166px), 3 agents add ~111px (card ≈ 200px) — live readout under the rail. Three is the comfortable ceiling in a 288px rail; at 4+ the Active group stops being scannable — recommend capping at 3 rows with a muted "+2 more panes" line in v2 rather than growing the card. Reduced motion stops the ring rotating (it stays a static hairline circle).
